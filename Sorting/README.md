# Sorting Algorithms

This folder contains Python implementations of common sorting algorithms. Each script demonstrates a different sorting technique, useful for learning algorithm fundamentals and understanding time complexity tradeoffs.

## Files

- `bubble_sort.py` - Sorts a list by repeatedly swapping adjacent elements until the list is ordered.
- `insertion_sort.py` - Builds the sorted list one element at a time by inserting each new element into its correct position.
- `merge_sort.py` - Uses a divide-and-conquer approach to recursively split, sort, and merge subarrays.
- `quick_sort.py` - Sorts by partitioning the array around a pivot and recursively sorting the partitions.
- `selection_sort.py` - Selects the smallest element from the unsorted portion and places it at the current position.
