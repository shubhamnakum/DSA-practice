# Basic Hashing

This folder contains Python practice problems focused on hashing concepts and frequency counting using dictionaries (hash maps). The examples demonstrate how to count occurrences in arrays and strings with simple hash-based logic.

## Files

- `Count_all_occurance.py` - Counts and prints the frequency of each element in a list or array.
- `Freq_char_in_string.py` - Counts character frequencies in a string.

## hash_map

This subfolder contains an example of using a hash map for array frequency counting.

- `frequency_ele_in_array.py` - Computes the frequency count of each element in an array using a dictionary.
