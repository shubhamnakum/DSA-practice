# Basic Recursion

This folder contains Python practice problems focused on basic recursion techniques. The examples demonstrate recursive printing, counting, and functional recursion patterns such as factorials, Fibonacci, array reversal, and summation.

## Files

- `print_all_num_till_N.py` - Recursively prints all numbers from 1 to N.
- `print_all_num_till_N_reverse.py` - Recursively prints all numbers from N down to 1.
- `print_Num_till_N_without_linearly.py` - Uses recursion to print numbers up to N without a linear loop structure.
- `Print_N_times_Recursion.py` - Prints a message or number N times using recursion.

## functional recursion

This subfolder contains recursive functions that return results instead of just printing output.

- `factorials.py` - Computes the factorial of a number using recursion.
- `fibonacci_multiple_rec.py` - Generates Fibonacci numbers with recursive calls.
- `reverse_array.py` - Reverses an array using recursion.
- `sum_till_N.py` - Computes the sum of numbers from 1 to N recursively.
