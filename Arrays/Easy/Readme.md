# Arrays Easy

This folder contains easy-level array practice problems in Python. Each script demonstrates a common array operation or technique, designed to build familiarity with searching, sorting, rotation, frequency counting, and subarray problems.

## Files

- `intersection_1.py` - Finds the intersection of two sorted arrays using the brute force approach.
- `intersection_2.py` - Finds the intersection of two sorted arrays using the two-pointer approach.
- `is_array_sorted.py` - Checks whether a given array is sorted.
- `largest_element_1.py` - Finds the largest element in the array using a brute force approach.
- `largest_element_2.py` - Finds the largest element in the array using an optimal approach.
- `linear_search.py` - Searches for a target element in the array using linear search.
- `longest_subarray_with_sum_k_1.py` - Finds the longest subarray with a given sum using a brute force approach.
- `longest_subarray_with_sum_k_2.py` - Finds the longest subarray with a given sum using a hashing approach.
- `longest_subarray_with_sum_k_3.py` - Finds the longest subarray with a given sum using a two-pointer approach.
- `max_consective_ones_1.py` - Computes the maximum number of consecutive ones in the array using a brute force approach.
- `missing_element_1.py` - Finds the missing element from a sequence from 1 to N.
- `missing_element_2.py` - Finds the missing element from a sequence from 1 to N using hashing.
- `missing_elements_3.py` - Finds the missing element from a sequence from 1 to N using summation.
- `missing_elements_4.py` - Finds the missing element from a sequence from 1 to N using XOR.
- `move_zeros_to_end_1.py` - Moves all zeros to the end using a brute force approach.
- `move_zeros_to_end_2.py` - Moves all zeros to the end using a two-pointer approach.
- `num_appears_once_1.py` - Finds the number that appears once in an array using a brute force approach.
- `num_appears_once_2.py` - Finds the number that appears once in an array using a hashing approach.
- `num_appears_once_3.py` - Finds the number that appears once in an array using XOR.
- `remove_duplicates_1.py` - Removes duplicate elements from a sorted array in-place using a brute force approach.
- `remove_duplicates_2.py` - Removes duplicate elements from a sorted array in-place using a two-pointer approach.
- `reverse_array.py` - Reverses an array.
- `rotate_by_1_element.py` - Rotates each element in an array by one position.
- `rotate_by_d_elements_1.py` - Rotates each element in an array by D positions using a brute force approach.
- `rotate_by_d_elements_2.py` - Rotates each element in an array by D positions using an optimal approach.
- `second_largest_1.py` - Finds the second largest element in the array using a brute force approach.
- `second_largest_2.py` - Finds the second largest element in the array using a better approach.
- `second_largest_3.py` - Finds the second largest element in the array using a better approach.
- `union_1.py` - Finds the union of two arrays using a brute force approach.
- `union_2.py` - Finds the union of two sorted arrays using a two-pointer approach.
